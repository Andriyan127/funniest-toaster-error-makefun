## The entry

One line, at most 120 characters — the error message a kitchen toaster
shows its owner when something goes wrong. The toaster as a
passive-aggressive coworker, setting a relationship boundary instead of
erroring out:

```
As of today, I only toast on a first-name basis. We're not there yet.
```

69 characters. No bread union, no ERROR codes, no "toasted exactly as
requested", no hostage jokes — a fresh angle in a 170-entry field.
